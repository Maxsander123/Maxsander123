## Featured Project

### [netbox-cli](https://github.com/Maxsander123/netbox-cli)
Python CLI tool for managing Netcup VPS servers via the Netcup API.

**Features:**
- OAuth2-based login with persistent & encrypted token storage
- Automatic token refresh -- no re-login required
- Server listing with detailed info
- Power management: start, stop, reset
- Snapshot management: list, create, restore, delete
- Traffic monitoring with CSV export
- Clean terminal output via Rich
- Shell completion for Bash, Zsh & Fish

## Homelab

My homelab is where I test container setups, experiment with networking and run self-hosted services. Current stack includes Pi-hole for DNS filtering, Home Assistant for automation, Bitwarden for password management and a Raspberry Pi as the backbone. I also run NVIDIA GPU workloads for local AI inference.
